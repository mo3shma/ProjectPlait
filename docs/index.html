On-device AI, held to rules.

Pick Gemini Nano or a small open model you download once. Every answer Plait shows goes through the same steps.

  1. Clean input. Links, dial-ins, styles and signatures are removed in code before the model sees anything.
  2. Rules apart from material. Instructions sit in the system message; your invite and notes are fenced off as material.
  3. Low temperature, fixed shape. The model answers in a set structure and keeps to the likeliest words.
  4. Checked in code. Lengths, links and every name and number are checked against the source. Anything that fails is dropped.
  5. Rules as the fallback. If nothing passes, plain rules take over. Nothing is sent to a server, ever.
